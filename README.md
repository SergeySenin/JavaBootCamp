# Java BootCamp

Учебный репозиторий с набором задач по Java: каждая задача вынесена в
отдельный пакет `task_<номер>/<название>/v1` с консольными демо-классами,
а в `src/main/resources` лежат готовые датасеты для практики с коллекциями и потоками данных.

## Быстрый старт

### Сборка
1. Установите JDK (Gradle Wrapper есть в репозитории).
2. Соберите проект: `./gradlew clean build` (Linux/macOS) или `./gradlew.bat clean build` (Windows PowerShell).

### Запуск демо-классов
После сборки готовые классы лежат в `build/classes/java/main`. Каждый модуль имеет собственный `Demo` с `main`:
- пример для спеллкастинга (task 14):
  - Linux/macOS: `java -cp build/classes/java/main org.study.bootcamp.task_14.lambda_spellcasting.v1.api.cli.Demo`
  - Windows PowerShell: `java -cp ".\build\classes\java\main" org.study.bootcamp.task_14.lambda_spellcasting.v1.api.cli.Demo`
- аналогично запускаются другие демо-классы, подставляя нужный пакет `org.study.bootcamp.task_<номер>...Demo`.

## Структура проекта

### Учебные задачи
Пакеты в `src/main/java/org/study/bootcamp` сгруппированы по номерам заданий
(например, `task_14/lambda_spellcasting`, `task_28/matrix_transform`, `task_43/people_directory`) и содержат
базовую модель, сервисы и консольные точки входа для тренировки в коллекциях, Stream API, обработке данных и работе с ООП.

### Учебные датасеты
В `src/main/resources` размещены вспомогательные наборы данных:
профили пользователей, продукты и заказы, вакансии, оценки студентов и CSV с экологическими показателями.
Их можно использовать для упражнений по фильтрации, агрегации и сериализации.

## Зависимости и сборка
Проект собирается плагином `java` и использует минимальный набор библиотек:
SLF4J и Logback для логирования, Lombok для генерации шаблонного кода, Apache Commons Lang3 и Gson для утилит,
JUnit Jupiter и Mockito для тестирования. Версии закреплены в `build.gradle` и подтягиваются через Maven Central.

## Тестирование
В репозитории нет модуля `src/test`, поэтому автоматические тесты не включены.
Команда `./gradlew test` полезна для проверки, что проект компилируется без ошибок.
