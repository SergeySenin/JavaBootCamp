# Задание 02. Бронирование железнодорожного билета

Вы разрабатываете консольную программу для оформления железнодорожного билета.

Пользователь должен ввести данные пассажира и поездки.
Программа должна обработать введённые значения, зарегистрировать продажу одного билета,
рассчитать продолжительность поездки и сформировать электронный билет.

## Структура программы

Создайте класс «решение» (`Solution`).

В классе создайте главный метод программы (`main`).

Для чтения данных с клавиатуры подключите класс «сканер» (`Scanner`) из пакета `java.util`
и создайте объект «консоль» (`console`), который
получает данные из стандартного потока ввода (`System.in`).

## Ввод данных

Программа должна последовательно получить от пользователя следующие значения.

### Текстовые данные

С помощью метода «считать строку» (`nextLine()`) получите:

1. «имя пассажира» (`passengerNameInput`);
2. «электронную почту» (`emailInput`);
3. «город отправления» (`departureCityInput`);
4. «город назначения» (`arrivalCityInput`);
5. «стоимость билета в виде текста» (`ticketPriceText`);
6. «продолжительность поездки в минутах в виде текста» (`travelMinutesText`).

Значения `ticketPriceText` и `travelMinutesText` на этом этапе должны
оставаться строками (`String`), даже несмотря на то, что внутри них находятся цифры.

### Числовые данные

После текстовых данных считайте:

* «количество свободных мест» (`availableSeats`)
  типа «целое число» (`int`) методом `nextInt()`;
* «количество уже проданных билетов» (`soldTickets`)
  типа «целое число» (`int`) методом `nextInt()`;
* «расстояние маршрута в километрах» (`routeDistance`)
  типа «вещественное число двойной точности» (`double`) методом `nextDouble()`.

Также непосредственно в коде создайте
переменную «номер вагона» (`carriageNumber`) типа «байт» (`byte`) со значением `7`.

## Обработка текстовых данных

### 1. Имя пассажира

Создайте переменную «имя пассажира» (`passengerName`) типа `String`.

Запишите в неё значение `passengerNameInput`, предварительно удалив
пробелы в начале и конце строки методом «удалить пробелы по краям» (`trim()`).

Создайте переменную «длина имени пассажира» (`passengerNameLength`) типа `int`.

С помощью метода «длина строки» (`length()`) сохраните
в неё количество символов очищенного имени пассажира (`passengerName`).

### 2. Электронная почта

Создайте переменную «электронная почта» (`email`) типа `String`.

Значение должно быть получено из `emailInput` в два этапа:

1. удалить пробелы по краям методом `trim()`;
2. преобразовать все буквы в нижний регистр методом `toLowerCase()`.

Исходную переменную `emailInput` изменять не требуется.

### 3. Маршрут

Создайте переменные:

* «город отправления» (`departureCity`);
* «город назначения» (`arrivalCity`).

В каждую из них запишите соответствующую исходную строку после обработки методом `trim()`.

После этого создайте переменную «название маршрута» (`routeName`) типа `String`.

Она должна содержать маршрут в обычном регистре:

`Helsinki - Tampere`

Создайте ещё одну переменную «отображаемое название маршрута» (`routeDisplayName`)
и сначала присвойте ей значение переменной `routeName`.

После присваивания преобразуйте
**только** `routeDisplayName` в верхний регистр методом `toUpperCase()`.

В результате:

* `routeName` должно сохранить обычный регистр;
* `routeDisplayName` должно содержать маршрут в верхнем регистре.

## Преобразование строк в числа

Переменная `ticketPriceText` содержит стоимость билета в виде строки.

Преобразуйте её в целое число с помощью метода:

`Integer.parseInt()`

Результат сохраните в переменной «стоимость билета» (`ticketPrice`) типа `int`.

Таким же способом преобразуйте `travelMinutesText` в переменную
«продолжительность поездки в минутах» (`travelMinutes`) типа `int`.

После преобразования дальнейшие арифметические операции
должны выполняться именно с числовыми переменными `ticketPrice` и `travelMinutes`.

## Расчёт продолжительности поездки

Продолжительность поездки хранится в `travelMinutes` как общее количество минут.

Создайте две переменные типа `int` одной сокращённой записью:

* «полные часы поездки» (`travelHours`);
* «оставшиеся минуты поездки» (`remainingMinutes`).

Рассчитайте:

`полные часы = общее количество минут / 60`

Для получения количества минут, оставшихся после выделения полных часов,
используйте оператор «остаток от деления» (`%`):

`оставшиеся минуты = общее количество минут % 60`

Например, `187` минут должны быть преобразованы в `3` часа и `7` минут.

## Регистрация продажи билета

До оформления билета переменная `soldTickets` содержит количество уже проданных билетов,
а `availableSeats` — количество оставшихся свободных мест.

После успешного оформления одного билета:

* увеличьте «количество проданных билетов» (`soldTickets`)
  ровно на единицу с помощью оператора «инкремент» (`++`);
* уменьшите «количество свободных мест» (`availableSeats`)
  ровно на единицу с помощью оператора «декремент» (`--`).

Для этих двух операций используйте именно `++` и `--`, а не обычное присваивание через `=`.

## Преобразование числа в строку

Преобразуйте значение переменной «стоимость билета» (`ticketPrice`)
из типа `int` в тип `String` с помощью метода:

`String.valueOf()`

Результат сохраните в отдельной переменной «стоимость билета текстом» (`ticketPriceAsText`).

Именно эту строковую переменную используйте хотя бы один раз при формировании электронного билета.

## Номер электронного билета

Создайте переменную «номер билета» (`ticketNumber`) типа `int` со значением `1000`.

После регистрации продажи увеличьте номер билета на единицу с помощью `++`.

Затем сформируйте строковую переменную «код билета» (`ticketCode`).

Она должна содержать текст:

`TRAIN-1001`

Числовую часть нельзя записывать внутрь строки вручную.
Используйте значение переменной `ticketNumber` и конкатенацию.

## Демонстрационный путь к файлу билета

Создайте переменную «путь к файлу билета» (`ticketFilePath`) типа `String`.

Она должна содержать:

```text
C:\Tickets\TRAIN-1001.txt
```

Обратные слеши должны быть записаны внутри строкового литерала
с помощью правильного экранирования (`\\`).

Код билета `TRAIN-1001` должен попадать в путь из переменной `ticketCode`.

## Формирование электронного билета

Сформируйте переменную «электронный билет» (`electronicTicket`) типа `String`.

Итоговый текст должен быть создан **одним строковым значением**, используя:

* конкатенацию `+`;
* перенос строки (`\n`);
* табуляцию (`\t`);
* экранированные двойные кавычки (`\"`);
* значения ранее созданных переменных.

Заголовок билета должен содержать текст в двойных кавычках:

`"RAILWAY TICKET"`

Кавычки должны входить в саму строку и поэтому должны быть экранированы.

## Тестовые входные данные

Для проверки программы последовательно введите:

```text
   Sergey Senin   
   SERGEY.EXAMPLE@MAIL.COM   
   Helsinki   
   Tampere   
2450
187
42
158
179,6
```

Первые четыре строки специально содержат лишние пробелы в начале и конце.

## Ожидаемые значения после обработки

После обработки данных должны получиться следующие значения:

* `passengerName` → `Sergey Senin`;
* `email` → `sergey.example@mail.com`;
* `routeName` → `Helsinki - Tampere`;
* `routeDisplayName` → `HELSINKI - TAMPERE`;
* `ticketPrice` → `2450`;
* `travelMinutes` → `187`;
* `travelHours` → `3`;
* `remainingMinutes` → `7`;
* `soldTickets` → `159`;
* `availableSeats` → `41`;
* `ticketNumber` → `1001`;
* `ticketCode` → `TRAIN-1001`;
* `ticketFilePath` → `C:\Tickets\TRAIN-1001.txt`.

## Итоговый вывод

После обработки всех данных выведите содержимое переменной `electronicTicket`.

Итоговый билет должен иметь следующий вид:

```text
"RAILWAY TICKET"
	Code: TRAIN-1001
	Passenger: Sergey Senin
	Email: sergey.example@mail.com
	Name length: 12
	Route: Helsinki - Tampere
	Route display: HELSINKI - TAMPERE
	Carriage: 7
	Distance: 179.6 km
	Travel time: 3 h 7 min
	Price: 2450
	Sold tickets: 159
	Available seats: 41
	File: C:\Tickets\TRAIN-1001.txt
```

Отступы перед строками данных должны быть созданы символом табуляции (`\t`),
а переходы между строками — управляющим символом переноса строки (`\n`).

## Требования к используемому синтаксису

Решение должно содержать:

* подключение класса `java.util.Scanner`;
* объект типа `Scanner`;
* оператор создания нового объекта (`new`);
* стандартный поток ввода (`System.in`);
* метод `nextLine()`;
* метод `nextInt()`;
* метод `nextDouble()`;
* тип `String`;
* тип `int`;
* тип `byte`;
* тип `double`;
* сокращённое объявление нескольких переменных одного типа;
* обычное присваивание (`=`);
* целочисленное деление (`/`);
* остаток от деления (`%`);
* инкремент (`++`);
* декремент (`--`);
* конкатенацию строк (`+`);
* пустую строку (`""`) хотя бы в одном корректном строковом выражении;
* метод `trim()`;
* метод `length()`;
* метод `toUpperCase()`;
* метод `toLowerCase()`;
* метод `String.valueOf()`;
* метод `Integer.parseInt()`;
* экранирование переноса строки (`\n`);
* экранирование табуляции (`\t`);
* экранирование обратного слеша (`\\`);
* экранирование двойной кавычки (`\"`);
* вывод результата через `System.out.println()`.

## Дополнительное требование к пустой строке

Чтобы отдельно закрепить работу с пустой строкой (`""`),
создайте переменную «префикс» (`prefix`) типа `String` со значением `""`.

Сформируйте `ticketCode` так, чтобы `prefix` участвовала в конкатенации,
но итоговое значение всё равно осталось:

`TRAIN-1001`

## Критерии выполнения

Задание выполнено правильно, если:

1. программа компилируется и запускается;
2. данные действительно считываются с клавиатуры через `Scanner`;
3. строковые данные обрабатываются методами
   `trim()`, `toLowerCase()`, `toUpperCase()` и `length()`;
4. исходная переменная `routeName` после создания `routeDisplayName`
   сохраняет значение `Helsinki - Tampere`;
5. строки `ticketPriceText` и `travelMinutesText`
   преобразуются в `int` методом `Integer.parseInt()`;
6. продолжительность поездки вычисляется с помощью `/` и `%`;
7. `soldTickets` изменяется оператором `++`;
8. `availableSeats` изменяется оператором `--`;
9. числовая стоимость преобразуется в строку через `String.valueOf()`;
10. итоговый код билета рассчитывается из значения переменной,
    а не содержит вручную записанное число `1001`;
11. путь `C:\Tickets\TRAIN-1001.txt` формируется с использованием экранированных обратных слешей;
12. итоговый билет содержит экранированные кавычки, переносы строк и табуляцию;
13. при тестовых входных данных программа получает указанные ожидаемые значения;
14. итоговый вывод соответствует заданному формату.
