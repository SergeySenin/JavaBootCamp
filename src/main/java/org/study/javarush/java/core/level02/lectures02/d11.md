Конвертация между типами данных

## 1. Зачем нужна конвертация типов?

Java — это строго типизированный язык. Если у компьютера есть «коробочка» для числа, то
попытка засунуть туда текст — примерно то же самое, что и попытка вставить вилку
в USB-разъём. Компилятор вам такое не простит! 😡

Однако в жизни мы часто работаем одновременно с разными типами данных. Например, у вас есть
строка, которая содержит число. Вот тут-то и нужна конвертация, или преобразование, типов.

Рассмотрим пример. Допустим, вы хотите хранить количество пользователей:

```
int a = 1;
int b = "2";
int c = "три";
```

Компилятор тут сразу скажет: «Ты меня за кого держишь? Я не умею автоматически преобразовывать
строку в число. Без тебя никак. Нужно привести строку к числу явно».

В Java есть несколько путей конвертации, и каждый — со своими плюсами, минусами и типичными
граблями.

## 2. Преобразуем int в String

В работе часто требуется получить строковое представление числа: например, чтобы вывести
его на экран, сохранить в файл, передать по сети, объединить с текстом и т. д. В Java для этого
существует сразу несколько способов, каждый из которых удобен в разных ситуациях.

### Метод String.valueOf()

Это основной и самый распространённый способ:

```
int number = 42;
String str = String.valueOf(number); // str содержит строку "42"
```

Метод String.valueOf() преобразует переданное значение в строку.

### Конкатенация с пустой строкой

Старый, но рабочий способ:

```
int number = 42;
String str = "" + number; // str содержит строку "42"
```

Такой подход быстро работает для простых случаев, но он менее явен для программиста, который
читает код.

## 3. Неявное преобразование в строку

Как уже говорилось выше, разработчики Java сделали так, что практически любое значение
можно преобразовать к типу String.

Более того, это автоматически происходит, когда мы складываем значение типа String
с каким-нибудь другим типом. Примеры:

```
int a = 5;
String name = "Аня" + a;           // name содержит строку Аня5

int b = 5;
String city = b + "New York" + b;  // city содержит строку 5New York5

int number = 10;
String code = "Yo";
String message = "Hello! " + number + code;
```

```text
message содержит строку Hello! 10Yo
```

Во всех трёх примерах мы спокойно складывали значения типа int и String, и в результате
всегда получался тип String.

Важно! Арифметические операции со строками проводить нельзя. Даже если строка целиком
состоит из цифр, она всё равно остаётся строкой.

Примеры:

```
int a = 5;
String name = "1" + a;                // name содержит строку 15

int b = 5;
String city = b + "9" + b;            // city содержит строку 595

int number = 10;
String code = "10";
String message = "" + number + code;  // message содержит строку 1010
```

Операция сложения выполняется слева направо, так что результат может быть немного
неожиданным. Пример:

```
int a = 5;
String name = a + a + "1" + a; // name содержит строку 1015
```

Порядок выполнения:

```text
((a + a) + "1") + a
```

Сначала `a + a` даёт число 10. Затем число 10 складывается со строкой `"1"`, превращается
в строку `"10"` и склеивается с `"1"`. Получается строка `"101"`. После этого к ней
приклеивается последнее значение `a`, то есть 5. В итоге получается строка `"1015"`.

## 4. Преобразование строки в число

Чтобы преобразовать число в строку в Java, достаточно сложить его с пустой строкой:

```
String str = "" + число;
```

А что делать, если нужно преобразовать строку в число? Любую строку в число преобразовать
нельзя. Но если строка содержит корректную запись целого числа, то это можно сделать.
Для этого в Java есть специальный метод.

Выглядит эта команда так:

```
int x = Integer.parseInt(строка);
```

Преобразование строки в число

Где `int x` — это объявление целочисленной переменной x, а `строка` — это число, заданное
в виде строки.

Примеры:

```
String str = "123";
int number1 = Integer.parseInt(str);        // number1 содержит число 123

int number2 = Integer.parseInt("321");      // number2 содержит число 321

int number3 = Integer.parseInt("321" + 0);  // number3 содержит число 3210

int number4 = "321";                        // Не скомпилируется: переменная типа int,
                                            // а значение типа String
```

Для отрицательных значений это тоже работает: метод Integer.parseInt() умеет обрабатывать
строки вида `"-123"`.

Но если строка не является корректной записью целого числа или число выходит за диапазон int,
программа завершится с ошибкой.

```
int number1 = Integer.parseInt("123");    // OK
int number2 = Integer.parseInt("-123");   // OK
int number3 = Integer.parseInt("три");    // Ошибка
int number4 = Integer.parseInt("123.5");  // Ошибка
```
