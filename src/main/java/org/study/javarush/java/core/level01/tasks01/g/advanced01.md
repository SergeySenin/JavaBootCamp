# Задание 01. Оформление заказа в маркетплейсе

Вы разрабатываете небольшую часть программы маркетплейса.
Программа должна рассчитать стоимость заказа и вывести в консоль подробный чек.

Все исходные данные задаются непосредственно в коде. Ввод данных с клавиатуры не требуется.

## Структура программы

Создайте класс «решение» (`Solution`).

В классе создайте главный метод программы (`main`), с которого начнётся выполнение команд.

Все переменные, вычисления и команды вывода разместите внутри метода `main`.

## Исходные данные

Создайте следующие переменные:

* «имя пользователя» (`userName`) типа «строка» (`String`) со значением `"Alice"`;
* «название товара» (`productName`) типа «строка» (`String`) со значением `"Mechanical Keyboard"`;
* «цена товара» (`itemPrice`) типа «целое число» (`int`) со значением `4800`;
* «количество товаров» (`itemCount`) типа «целое число» (`int`) со значением `3`;
* «стоимость доставки» (`deliveryPrice`) типа «целое число» (`int`) со значением `600`;
* «скидка» (`discount`) типа «целое число» (`int`) со значением `1200`;
* «сервисный сбор» (`serviceFee`) типа «целое число» (`int`) со значением `200`.

## Расчёты

1. Объявите переменную «стоимость товаров» (`itemsCost`)
   типа «целое число» (`int`) **без начального значения**.

2. Отдельной командой присвойте переменной «стоимость товаров» (`itemsCost`) результат умножения:

   `цена товара × количество товаров`

   Для вычисления используйте
   значения переменных «цена товара» (`itemPrice`) и «количество товаров» (`itemCount`).

3. Создайте переменную
   «стоимость заказа до скидки» (`orderCostBeforeDiscount`) типа «целое число» (`int`).

   Запишите в неё сумму:

   `стоимость товаров + стоимость доставки`

   Используйте значения
   переменных «стоимость товаров» (`itemsCost`) и «стоимость доставки» (`deliveryPrice`).

   В арифметическом выражении дополнительно используйте круглые скобки `()`.

4. Создайте переменную «скидка на один товар» (`discountPerItem`) типа «целое число» (`int`).

   Рассчитайте значение:

   `общая скидка / количество товаров`

   Для вычисления используйте
   переменные «скидка» (`discount`) и «количество товаров» (`itemCount`).

5. Создайте переменную «итоговая стоимость» (`totalCost`) типа «целое число» (`int`).

   Сначала присвойте ей результат:

   `стоимость заказа до скидки - скидка`

   Используйте переменные
   «стоимость заказа до скидки» (`orderCostBeforeDiscount`) и «скидка» (`discount`).

6. После этого выполните **повторное присваивание** переменной «итоговая стоимость» (`totalCost`).

   Новое значение должно быть рассчитано на основании её текущего значения:

   `текущая итоговая стоимость + сервисный сбор`

   Для этого используйте переменную «сервисный сбор» (`serviceFee`).

   Отдельную переменную для окончательной стоимости создавать не нужно.

7. Создайте переменную «итоговое сообщение» (`finalMessage`) типа «строка» (`String`).

   С помощью конкатенации сформируйте сообщение следующего вида:

   `Итого к оплате: 14000 руб.`

   Число итоговой стоимости нельзя записывать непосредственно внутрь строкового литерала.
   Значение должно быть получено из переменной «итоговая стоимость» (`totalCost`).

## Вывод в консоль

Программа должна вывести:

```text
Покупатель: Alice
Товар: Mechanical Keyboard
Цена за единицу: 4800 руб.
Количество: 3
Стоимость товаров: 14400 руб.
Доставка: 600 руб.
Стоимость до скидки: 15000 руб.
Скидка: 1200 руб.
Скидка на один товар: 400 руб.
Сервисный сбор: 200 руб.
Итого к оплате: 14000 руб.
```

## Требования к выводу

Строку с покупателем соберите с помощью двух команд.

Сначала выведите текст `Покупатель: `
методом «вывести без перехода на новую строку» (`System.out.print()`).

После этого выведите значение переменной «имя пользователя» (`userName`)
методом «вывести с переходом на новую строку» (`System.out.println()`).

Строку с названием товара сформируйте таким же способом:

* текст `Товар: ` — через `System.out.print()`;
* значение переменной «название товара» (`productName`) — через `System.out.println()`.

Остальные строки сформируйте с
помощью метода `System.out.println()` и конкатенации строк с переменными.

Последняя строка с итоговой стоимостью должна
выводить содержимое переменной «итоговое сообщение» (`finalMessage`).

## Требования к используемому синтаксису

Решение должно содержать:

* класс «решение» (`Solution`);
* главный метод программы (`main`);
* переменные типа «целое число» (`int`);
* переменные типа «строка» (`String`);
* объявление переменной одновременно с присваиванием начального значения;
* отдельное объявление переменной без начального значения;
* отдельную операцию присваивания с помощью `=`;
* повторное присваивание нового значения уже существующей переменной;
* сложение `+`;
* вычитание `-`;
* умножение `*`;
* деление `/`;
* круглые скобки `()` внутри арифметического выражения;
* конкатенацию строк с помощью `+`;
* конкатенацию значения типа `String` со значением типа `int`;
* метод вывода без перехода на новую строку (`System.out.print()`);
* метод вывода с переходом на новую строку (`System.out.println()`).

Имена всех переменных должны точно соответствовать указанным в задании английским именам в скобках.

Значения, которые являются результатом вычислений,
должны получаться из переменных и арифметических выражений.

Поэтому значения:

* `14400` — стоимость товаров;
* `15000` — стоимость до скидки;
* `400` — скидка на один товар;
* `14000` — итоговая стоимость

не должны записываться непосредственно в команды вывода или строковые литералы.

## Критерии выполнения

Задание выполнено правильно, если:

1. программа компилируется и запускается;
2. программа начинает выполнение с главного метода (`main`);
3. вывод в консоли полностью совпадает с ожидаемым результатом;
4. все исходные значения хранятся в соответствующих переменных;
5. все вычисляемые значения получаются через арифметические выражения;
6. переменная «стоимость товаров» (`itemsCost`) сначала объявляется без значения,
   а затем получает значение отдельной операцией присваивания;
7. переменной «итоговая стоимость» (`totalCost`) значение присваивается более одного раза;
8. итоговое сообщение (`finalMessage`) формируется с
   помощью конкатенации строки и вычисленного значения;
9. изменение исходных значений цены, количества, доставки,
   скидки или сервисного сбора приводит к автоматическому пересчёту связанных с ними результатов.
