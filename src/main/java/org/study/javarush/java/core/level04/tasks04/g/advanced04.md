# Задание 04. Исследовательская миссия автономного дрона

Вы разрабатываете консольную программу управления исследовательским дроном.

Перед началом миссии оператор должен настроить параметры запуска.
После этого программа выполняет обратный отсчёт, принимает  неизвестное заранее
количество показаний датчика, последовательно проверяет контрольные точки маршрута,
прекращает поиск после обнаружения маяка и выводит карту исследуемой области.

## Структура программы

Создайте класс «решение» (`Solution`).

В классе создайте главный метод программы (`main`).

Для чтения данных с клавиатуры подключите класс «сканер» (`Scanner`) из пакета `java.util`.

Создайте объект «консоль» (`console`), который
получает данные из стандартного потока ввода (`System.in`).

# Этап 1. Название миссии

Запросите у пользователя «название миссии» (`missionNameInput`) типа `String`.

Удалите пробелы в начале и конце строки методом `trim()` и
сохраните результат в переменной «название миссии» (`missionName`).

# Этап 2. Проверка заряда аккумулятора

Создайте переменную «уровень заряда» (`batteryLevel`) типа `int`.

Программа должна запросить уровень заряда аккумулятора **хотя бы один раз**.

Допустимый уровень заряда:

`от 20 до 100 включительно`.

Для проверки используйте цикл «с постусловием» (`do-while`).

Если пользователь вводит значение меньше `20` или больше `100`, программа должна вывести:

```text
Invalid battery level.
```

и повторить запрос.

Когда введено допустимое значение, цикл должен завершиться.

После этого выведите:

```text
Battery accepted: [уровень заряда]%
```

Значение должно подставляться из переменной `batteryLevel`.

# Этап 3. Параметры маршрута

Считайте с клавиатуры:

* «количество контрольных точек» (`checkpointCount`) типа `int`;
* «номер искомой контрольной точки» (`targetCheckpoint`) типа `int`;
* «размер карты» (`mapSize`) типа `int`;
* «строку маяка» (`beaconRow`) типа `int`;
* «столбец маяка» (`beaconColumn`) типа `int`.

Для этого задания предполагается, что:

* `checkpointCount` больше `0`;
* `targetCheckpoint` находится в диапазоне от `1` до `checkpointCount`;
* `mapSize` больше `0`;
* координаты маяка находятся внутри карты.

Дополнительную проверку этих значений выполнять не требуется.

# Этап 4. Обратный отсчёт перед запуском

Перед началом миссии выполните обратный отсчёт:

```text
3
2
1
LAUNCH
```

Для этого используйте цикл «со счётчиком» (`for`).

Счётчик должен:

* начинаться со значения `3`;
* уменьшаться после каждой итерации;
* завершить цикл после вывода `1`.

Для изменения счётчика используйте декремент (`--`).

Строку `LAUNCH` выведите после завершения цикла.

# Этап 5. Получение показаний датчика

После запуска дрон начинает передавать расстояния до обнаруженных объектов в метрах.

Заранее неизвестно, сколько показаний поступит.

Создайте:

* «показание датчика» (`sensorReading`) типа `int`;
* «количество показаний» (`sensorReadingCount`) типа `int` со значением `0`;
* «сумма показаний» (`sensorReadingSum`) типа `int` со значением `0`;
* «количество опасных объектов» (`dangerousObjectCount`) типа `int` со значением `0`.

Используйте цикл «с предусловием» (`while`).

Пользователь последовательно вводит расстояния.

Отрицательное число означает:

`передача показаний завершена`.

Отрицательное значение:

* не должно учитываться в количестве показаний;
* не должно добавляться в сумму;
* не должно учитываться как опасный объект.

Для каждого неотрицательного показания:

1. увеличьте `sensorReadingCount` на единицу;
2. прибавьте расстояние к `sensorReadingSum`;
3. если расстояние меньше или равно `100`, увеличьте `dangerousObjectCount` на единицу.

После завершения ввода выведите:

```text
Sensor readings: [количество]
Sensor sum: [сумма]
Dangerous objects: [количество опасных объектов]
```

## Пример

При вводе:

```text
450
90
210
40
-1
```

должны получиться:

* `sensorReadingCount` → `4`;
* `sensorReadingSum` → `790`;
* `dangerousObjectCount` → `2`.

# Этап 6. Проверка контрольных точек маршрута

Дрон должен последовательно проверить контрольные точки:

`от 1 до checkpointCount включительно`.

Для этого используйте цикл `for`.

Каждая **четвёртая** контрольная точка является закрытой зоной.

То есть контрольные точки:

`4, 8, 12, 16 ...`

сканировать нельзя.

Определяйте такие точки с помощью остатка от деления (`%`).

Если контрольная точка закрыта, выведите:

```text
Checkpoint [номер]: RESTRICTED
```

После этого используйте оператор «продолжить следующую итерацию» (`continue`).

На этой итерации никакая дальнейшая обработка контрольной точки выполняться не должна.

# Этап 7. Поиск маяка

Создайте переменную «маяк найден» (`targetFound`) типа `boolean` со значением `false`.

Для каждой контрольной точки, которая **не была пропущена** через `continue`, выведите:

```text
Checkpoint [номер]: scanning
```

После этого сравните текущий номер контрольной точки с `targetCheckpoint`.

Если номера совпадают:

1. присвойте `targetFound = true`;
2. выведите:

```text
TARGET FOUND AT CHECKPOINT [номер]
```

3. немедленно завершите цикл с помощью оператора «прервать цикл» (`break`).

После `break` оставшиеся контрольные точки проверяться не должны.

## Важное следствие

Если `targetCheckpoint` является каждой четвёртой точкой,
например `4` или `8`, сначала должен выполниться `continue`.

Следовательно, такая точка будет считаться закрытой зоной и маяк найден не будет.

Не изменяйте порядок этих проверок только ради получения `targetFound = true`.

# Этап 8. Результат поиска

После завершения цикла создайте переменную «результат поиска» (`searchStatus`) типа `String`.

Используйте тернарный оператор (`?:`):

* `"FOUND"`, если `targetFound == true`;
* `"NOT FOUND"` в противном случае.

Выведите:

```text
Search status: [результат]
```

# Этап 9. Построение карты области

После завершения поиска программа должна вывести квадратную текстовую карту размером:

`mapSize × mapSize`.

Используйте **два вложенных цикла ****`for`**:

* внешний цикл отвечает за строки (`row`);
* внутренний цикл отвечает за столбцы (`column`).

Индексация начинается с `0`.

Например, при `mapSize = 5`:

* строки имеют номера от `0` до `4`;
* столбцы имеют номера от `0` до `4`.

## Обозначения карты

Используйте:

* `"B"` — координата маяка;
* `"."` — обычная клетка.

Если одновременно выполняются условия:

```text
row == beaconRow
column == beaconColumn
```

выведите:

```text
B
```

иначе:

```text
.
```

Для объединения двух проверок используйте логическое «И» (`&&`).

После каждой клетки используйте `System.out.print()`.

После завершения внутреннего цикла используйте `System.out.println()`,
чтобы перейти на новую строку.

Например, для:

```text
mapSize = 5
beaconRow = 2
beaconColumn = 3
```

карта должна выглядеть так:

```text
.....
.....
...B.
.....
.....
```

# Этап 10. Итоговый отчёт миссии

После карты выведите:

```text
Mission: [название миссии]
Battery: [заряд]%
Sensor readings: [количество показаний]
Dangerous objects: [количество опасных объектов]
Target checkpoint: [искомая точка]
Search status: [FOUND/NOT FOUND]
Map size: [размер]x[размер]
```

Все изменяемые значения должны попадать в отчёт из соответствующих переменных.

# Дополнительные тесты для самопроверки

## Тест 2. Заряд сразу корректный

Введите допустимое значение аккумулятора при первой попытке.

Цикл `do-while` всё равно должен выполнить тело ровно один раз.

Это проверяет главное отличие `do-while`: тело выполняется хотя бы один раз.

## Тест 3. Маяк расположен в закрытой контрольной точке

Используйте:

```text
checkpointCount = 10
targetCheckpoint = 8
```

Ожидаемая логика:

* точка `4` → `RESTRICTED`;
* точка `8` → `RESTRICTED`;
* `TARGET FOUND...` не выводится;
* цикл продолжает работу до точки `10`;
* `targetFound` → `false`;
* `searchStatus` → `NOT FOUND`.

Этот тест проверяет, что `continue` выполняется **до** проверки искомой точки.

## Тест 4. Маяк найден сразу

Используйте:

```text
targetCheckpoint = 1
```

После первой контрольной точки должен сработать `break`.

Точки со `2` и далее выводиться не должны.

## Тест 5. Нет показаний датчика

Первым показанием датчика введите:

```text
-1
```

Тело цикла `while` обработки показаний не должно выполниться ни одного раза.

Результат:

* `sensorReadingCount` → `0`;
* `sensorReadingSum` → `0`;
* `dangerousObjectCount` → `0`.

Этот тест показывает отличие `while` от `do-while`.

# Требования к используемому синтаксису

Решение должно содержать:

* класс «решение» (`Solution`);
* главный метод программы (`main`);
* класс «сканер» (`Scanner`);
* стандартный поток ввода (`System.in`);
* тип `String`;
* тип `int`;
* тип `boolean`;
* цикл «с предусловием» (`while`);
* цикл «со счётчиком» (`for`);
* цикл «с постусловием» (`do-while`);
* точку с запятой после условия конструкции `do-while`;
* увеличение значения переменной (`++`);
* уменьшение значения переменной (`--`);
* накопление суммы внутри цикла;
* оператор остатка от деления (`%`);
* оператор сравнения (`==`);
* оператор «меньше или равно» (`<=`);
* логическое «И» (`&&`);
* условный оператор (`if`);
* оператор досрочного выхода из цикла (`break`);
* оператор перехода к следующей итерации (`continue`);
* тернарный оператор (`?:`);
* два вложенных цикла `for`;
* отдельные переменные-счётчики внешнего и внутреннего циклов;
* `System.out.print()`;
* `System.out.println()`.

# Требования к выбору циклов

Каждый вид цикла должен использоваться по указанному назначению:

* `do-while` — только для проверки заряда аккумулятора;
* `while` — для обработки неизвестного заранее количества показаний датчика;
* обычный `for` — для обратного отсчёта и перебора контрольных точек;
* вложенные `for` — для построения двумерной карты.

Не заменяйте один вид цикла другим только потому,
что итоговый результат можно получить несколькими способами.

Цель задания — закрепить различия между этими конструкциями.

# Требования к `break` и `continue`

Оператор `continue` должен использоваться именно для закрытых контрольных точек.

После выполнения `continue` код ниже него в текущей итерации выполняться не должен.

Оператор `break` должен использоваться только
после успешного обнаружения искомой контрольной точки.

После выполнения `break` весь цикл проверки контрольных точек должен завершиться.

# Требования к вложенным циклам

Для карты используйте отдельные счётчики:

* «строка» (`row`);
* «столбец» (`column`).

Переменная `column` должна объявляться как счётчик внутреннего цикла так,
чтобы при каждой новой строке перебор столбцов снова начинался с `0`.

# Критерии выполнения

Задание выполнено правильно, если:

1. программа компилируется и запускается;
2. название миссии очищается методом `trim()`;
3. `do-while` обязательно запрашивает заряд хотя бы один раз;
4. некорректный заряд приводит к новой итерации `do-while`;
5. обратный отсчёт выполняется циклом `for` с уменьшением счётчика;
6. цикл `while` корректно обрабатывает любое количество неотрицательных показаний;
7. отрицательное показание завершает ввод и не участвует в вычислениях;
8. количество, сумма и число опасных показаний вычисляются внутри цикла;
9. закрытые контрольные точки определяются с помощью `%`;
10. закрытая точка пропускается оператором `continue`;
11. код после `continue` на этой итерации не выполняется;
12. после обнаружения маяка используется `break`;
13. после `break` оставшиеся контрольные точки не проверяются;
14. `searchStatus` определяется по значению `targetFound`;
15. карта строится двумя вложенными циклами `for`;
16. внутренний цикл полностью выполняется заново для каждой строки карты;
17. координата маяка определяется по `row` и `column`;
18. основной и дополнительные тесты дают ожидаемое поведение.
